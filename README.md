## 🎨 Customization

### Colors
The website uses a modern color scheme that can be easily customized in `styles.css`:

- **Primary Blue**: `#2563eb` (used for links, buttons, accents)
- **Gradient Background**: `#667eea` to `#764ba2` (hero section)
- **Accent Yellow**: `#fbbf24` (call-to-action buttons)
- **Text Colors**: Various shades of gray for readability

### Content Updates

#### Personal Information
- Update your name, title, and description in `index.html`
- Modify statistics in the hero section
- Edit the About Me section with your details

#### Services
- Modify the two service cards in the Services section
- Update service descriptions and features
- Change service icons (using Font Awesome classes)

#### Portfolio/Works
- Update the three work cards with your projects
- Modify project descriptions and statistics
- Change work icons as needed

#### Contact Information
- Update email, location, and website in the contact section
- Modify the contact form fields if needed

### Images
Currently, the website uses Font Awesome icons as placeholders. To add real images:

1. Replace the icon elements with `<img>` tags
2. Add your images to the project folder
3. Update the CSS to style the images appropriately

## 🛠️ Troubleshooting

### Common Issues

1. **Font Awesome icons not showing**
   - Check internet connection (CDN dependency)
   - Verify Font Awesome CSS link

2. **Mobile menu not working**
   - Ensure JavaScript is enabled
   - Check for JavaScript errors in console

3. **Styles not loading**
   - Verify file paths are correct
   - Check CSS file exists in same directory

### Browser Console
Open browser developer tools (F12) to check for any JavaScript errors or missing resources.
